# 🏟️ fitRota

fitRota, sporseverlerin çevrelerindeki spor tesislerini (halı saha, tenis kortu, kapalı spor salonu vb.) kolayca bulup, uygun saatleri görüntüleyerek anında rezervasyon yapabilmelerini sağlayan bir mobil uygulamadır.

## 📖 Proje Hakkında

Geleneksel tesis kiralama süreçlerindeki telefonla arama, müsaitlik durumu sorma ve manuel kayıt tutma zorluklarını ortadan kaldırmak amacıyla geliştirilmiştir. Kullanıcılar tek bir ekran üzerinden lokasyonlarına en yakın tesisleri listeleyebilir, tesis sahipleri ise kendi sistemlerini dijital ortamda yönetebilir.

## ✨ Temel Özellikler

- **Kullanıcı Modülü:**
  - Konum bazlı spor tesisi arama ve filtreleme (tesis türü, fiyat, puan).
  - Tesislerin detaylı profilleri (fotoğraflar, sunulan imkanlar, kurallar).
  - Gerçek zamanlı saat ve tarih müsaitlik durumu kontrolü.
  - Hızlı rezervasyon oluşturma ve geçmiş rezervasyonları takip etme.
- **Tesis/Yönetici Modülü:**
  - Tesis bilgilerini ve çalışma saatlerini güncelleme.
  - Gelen rezervasyonları onaylama/reddetme ve takvim üzerinden görüntüleme.
  - Gelir ve doluluk oranlarını raporlama.

## 🛠️ Kullanılan Teknolojiler

- **Mobil Geliştirme:** Android Studio 
- **Backend & API:** C# / .NET 
- **Veritabanı:** MSSQL (İlişkisel veritabanı tasarımı, trigger ve view'ler kullanılarak optimize edilmiştir)
- **Versiyon Kontrolü:** Git & GitHub
